# Credit Control Helper 2.1 — интегриран редизайн

## Стартиране
1. Разархивирайте ZIP файла.
2. Отворете папката `Credit_Control_Helper_2_1` във Visual Studio Code.
3. Стартирайте `index.html` с Live Server.

## Пренесено в новия интерфейс
- Работни системи: директните адреси са извлечени от оригиналното меню.
- SQL: оригиналните заглавия, SQL примери и popup прозорци за базите.
- Коментари и шаблони: оригиналните текстове са пренесени в полета с бутон за копиране.
- Обща информация: оригиналните коментари.
- Robot: Daily Steps и оригиналните YES/NO popup инструкции.
- WhiteFlag: оригиналните проверки, бюджетни бележки, Credit Limit и WF Rules popup-и.
- Работен график: задачите по трите смени и двата оригинални Google Sheets embed-а.
- Оригиналните HTML/JS/CSS/Excel и image файлове са запазени. `original-tools.html` съдържа старата страница като резервно копие.

## Забележки за проверка
- Някои оригинални URL-и са били невалидно форматирани или съкратени в изходния HTML (вкл. Siebel и EGN check). За тях е поставен базов адрес и е необходима проверка от служебната мрежа.
- В popup HTML файловете паролоподобните стойности са заменени с указание да се ползва официалният достъп от IT. Пароли не са пренесени в новия код.
- Вътрешните адреси с IP ще работят само при достъп до съответната служебна мрежа/VPN.
- SQL примерите са демонстрационни и маскираните стойности са оставени като placeholders.

## Месечна актуализация на графика — Google Drive / Google Sheets
Запазен е предишният начин на работа: графикът се показва чрез вграден Google Sheets прозорец.

### Как да смениш графика всеки месец
1. Качи новия Excel файл в Google Drive.
2. Отвори файла с Google Sheets (ако е нужно, избери „Отваряне с → Google Таблици“).
3. В Google Sheets избери **Файл → Споделяне → Публикуване в мрежата** или използвай **Файл → Споделяне → Вграждане** (според интерфейса, който виждаш).
4. Копирай адреса за вграждане (Embed URL), който съдържа `docs.google.com/spreadsheets/d/...`.
5. В `index.html` намери секцията `Актуален работен график` и замени само адреса в `src="..."` на първия iframe.
6. Не променяй iframe-а в секцията `Архивен график – October 2026`, ако искаш да запазиш октомври като архив.
7. Запази файла, тествай с Live Server и качи промените в GitHub.

**Важно:** текущият iframe временно използва наличния Google Sheets адрес от предишния график. След като качиш новия месечен файл, задължително замени този адрес с новия Embed URL, за да не се показва октомври като актуален график.
